# Deploy Flow

这个文档用于固定私密投票案例的部署路径。

## 第一阶段部署目标

第一阶段只要求读者能完成两件事：

- 在本地节点部署合约
- 知道未来如何迁移到 Sepolia

## 推荐顺序

### 1. 先在 mocked mode 下完成测试

这样可以先确认：

- 合约逻辑是通的
- 时间窗口和重复投票规则是通的
- 目录结构没有问题

### 2. 再启动本地节点

推荐命令路径：

```bash
npx hardhat node
```

### 3. 部署到 localhost

```bash
npx hardhat deploy --network localhost
```

### 4. 记录部署结果

至少应记录：

- 合约地址
- 使用的网络
- 部署时的初始化参数

这样后续前端接入时才不会混乱。

## 第二阶段再做什么

当本地流程稳定之后，再继续：

- 配置 `MNEMONIC`
- 配置 `INFURA_API_KEY`
- 部署到 `sepolia`
- 做真实网络验证

## 教程中的提醒

部署章节一定要提醒读者：

- localhost 主要用于联调和演示
- Sepolia 才是更接近真实链路的验证环境
- 不要把网络问题和合约逻辑问题混在一起排查
