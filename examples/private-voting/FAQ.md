# Private Voting FAQ

## 为什么我已经部署了合约，前端还是读不到内容

先检查两件事：

- 你粘贴的合约地址是否正确
- 钱包是否连到了你部署时使用的那条链

如果你是本地部署，最常见的问题其实是钱包网络没有切到本地链。

## 为什么本地前端里不能直接把完整隐私流程全演示出来

因为这套案例默认先把“本地链 + mock 测试 + 公开状态界面”跑顺。

真实浏览器端加密输入和结果解密，更适合在读者自行部署到测试网后继续验证。

## 为什么结果发布前看不到票数

这是合约和前端共同遵守的业务规则，不是页面错误。
